# Image tab

- Treat an image command as a two-phase edit: write every selected frame into a new per-operation directory, then change timeline paths only after all FFmpeg calls and output-existence checks succeed. Delete the whole staging directory on cancellation or failure. This prevents the first frames of a multi-selection from changing when a later FFmpeg invocation fails.
- Materialize every replacement thumbnail before changing any live frame path or collection. Successful file generation is not yet a commit: bitmap decoding can still fail and must leave the timeline and selection untouched.
- Decode timeline thumbnails to a bounded longest edge and keep the source dimensions separately for Statistics; a 106×70 card must not retain a full-resolution bitmap per frame. Use a virtualizing timeline panel so large imported sequences do not instantiate every card.
- Bulk per-frame FFmpeg work uses a small bounded worker pipeline. A serial process launch for every frame makes ordinary video-sized selections operationally unusable even though cancellation exists.
- Serialize awaited mutations behind one operation gate, stop playback on entry, and prevent status-bar playback from restarting until cleanup releases the gate. Selection changes during an await otherwise make snapshots target different editor states.
- History snapshots may reference workspace files directly only while workspace cleanup owns their lifetime. Never delete a replaced PNG when committing or disposing a history entry: another undo, redo, baseline, or current state can still refer to it.
- FFmpeg filters that match the Linux normalized-PNG model are `scale=…:flags=lanczos`, `crop=w:h:x:y`, `hflip`, `vflip`, `transpose=clock`, and `transpose=cclock`. Keep each frame's delay and relative position unchanged when replacing its path.
- Crop coordinates accept zero but dimensions do not. Validate these separately before starting FFmpeg so invalid dialog input cannot leave a staging artifact.
- Border and whole-frame drop shadow are bounded transforms on normalized PNGs and should use the same staged replacement path. Text, region-selected overlay/obfuscation, mask, capture-metadata, and annotation controls need additional authoring state; leave them disabled until that subsystem exists and state the dependency in each tooltip.
- Transform regressions need landmark-pixel oracles, not only output dimensions or a changed digest. Assert crop origins, horizontal versus vertical coordinate mapping, clockwise versus counter-clockwise mapping, and both content and padding colors for border/shadow; otherwise the wrong filter can satisfy the test.
- Bound transform output dimensions and total pixels before launching FFmpeg. Border arithmetic must be checked against each source frame's decoded dimensions; positivity alone admits overflow-sized filters and resource-exhausting outputs.
